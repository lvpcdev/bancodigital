# Requisitos iniciais — rascunho legado

- RF01 — O sistema deve fazer PIX rapidamente.
- RF02 — O sistema deve fazer TED.
- RF03 — O sistema deve emitir cartão.
- RF04 — O sistema deve avisar o cliente.
- RNF01 — O sistema deve ser seguro.
- RNF02 — O sistema deve ter bom desempenho.
- RNF03 — O sistema deve ficar disponível sempre.

Não existe prioridade, critério mensurável, origem do requisito ou vínculo com decisões de arquitetura.
