# Contexto atual — FinCore

O FinCore é um banco digital didático que mantém contas e permite operações como PIX e TED, emissão de cartões, cálculo de tarifas, análise antifraude e notificações.

## Atores principais
- Cliente da conta.
- Equipe responsável pela operação e evolução do FinCore.

## Sistemas externos observados no código
- Cliente legado de PIX.
- Cliente legado de TED.
- Gateway legado de SMS.
- API legada de WhatsApp.

## Onde confirmar
Consulte `src/main/java/br/edu/fincore/` e os requisitos em `docs/requisitos/`.
